# AGENTS.md — вход для агентов, кроме Claude Code

Codex, Cursor и другие агенты читают этот файл. Правила одни на всех —
они в [`CLAUDE.md`](CLAUDE.md): прочитай его целиком и действуй по нему.

Коротко:
- отвечай из репо и **цитируй источник** (путь файла, задача, ссылка);
- в репо нет ответа — так и скажи, не выдумывай;
- репо разошлось с кодом/трекером — права система записи, покажи обе версии;
- в репо ничего не пиши напрямую: ветка + PR;
- граница доверия (зарплаты, PII клиентов, цифры коммерческих условий,
  секреты) — в `CLAUDE.md`.
