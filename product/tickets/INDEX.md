# Ответы из тикетов поддержки

> Что сюда писать: проверенные ответы на повторяющиеся обращения клиентов,
> разложенные по темам (один файл — одна тема, не одна большая свалка:
> агенту дорого читать огромный файл ради одного ответа). Только
> обезличенные формулировки, без имён, телефонов и переписки клиентов.
> Ниже — пример (Acme), замените.

Первый источник для вопросов «почему не получается / что значит ошибка».

| Тема | Файл | Ответов |
|---|---|---|
| Создание, перенос и отмена записи | [`booking-errors.md`](booking-errors.md) | 2 |

Формат ответа в файле темы: **симптом** → **причина** → **что ответить** →
**источник** (код, страница API, задача).
