# Создание записи

> Пример страницы API (Acme). Формат: метод, обязательные поля, ответы,
> частые ошибки со ссылкой на тикеты. Замените своим.

`POST /v1/bookings` — создать запись клиента к мастеру.

| Поле | Обязательно | Что |
|---|---|---|
| `master_id` | да | мастер |
| `service_id` | да | услуга; задаёт длительность |
| `starts_at` | да | начало слота, ISO 8601 с часовым поясом |
| `client_phone` | нет | для SMS-напоминания |

Ответ `201`: запись в статусе `pending` (статусы — `brain/product/object-model.md`).

| Ошибка | Когда | Что ответить клиенту |
|---|---|---|
| `409 slot_taken` | слот заняли между выбором и подтверждением | выбрать другой слот; см. `../tickets/booking-errors.md` |
| `422 invalid_starts_at` | время без часового пояса | передавать `starts_at` с поясом |
